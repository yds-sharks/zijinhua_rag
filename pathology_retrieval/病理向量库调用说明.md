# 病理向量库调用说明

本文档说明这两个新交付脚本的使用方式：

- `pathology_vector_db_server.py`：常驻检索服务，启动一次后持续加载模型和 Milvus 库。
- `call_pathology_vector_db.py`：调用脚本，优先请求常驻服务；服务不可用时默认回退为本地直连加载。

默认病理向量库配置来自：

```bash
/mnt/data_1/yds/RAG/Hybrid_milvus/总版/insert/config.yaml
```

当前确认的库信息：

```text
Milvus DB:   /mnt/data_1/yds/RAG/Hybrid_milvus/总版/数据库/bm25.db
Collection:  cervix_v3
向量数量:     1,783,317
模型路径:     /mnt/data_1/yds/RAG/Hybrid_milvus/总版/pretrained_models/BAAI/bge-m3
```

## 推荐用法：常驻服务

第一次启动服务：

```bash
cd /mnt/data_1/yds/RAG/Hybrid_milvus/总版
python3 pathology_vector_db_server.py --host 127.0.0.1 --port 8765
```

服务启动时会加载 jieba、BGE 模型和 Milvus Lite 数据库。178 万向量库首次加载会比较慢，看到下面日志说明服务已经可用：

```text
[startup] ready on http://127.0.0.1:8765
```

另开一个终端调用检索：

```bash
cd /mnt/data_1/yds/RAG/Hybrid_milvus/总版
python3 call_pathology_vector_db.py '宫颈癌的病理诊断要点是什么？' --topk 3 --json
```

检查服务状态：

```bash
curl -s http://127.0.0.1:8765/health
```

返回示例：

```json
{
  "status": "ok",
  "config": "/mnt/data_1/yds/RAG/Hybrid_milvus/总版/insert/config.yaml",
  "milvus_uri": "/mnt/data_1/yds/RAG/Hybrid_milvus/总版/数据库/bm25.db",

```

## 代码一：pathology_vector_db_server.py

作用：启动常驻 HTTP 检索服务，避免每次查询都重新加载模型和向量库。

完整路径：

```bash
/mnt/data_1/yds/RAG/Hybrid_milvus/总版/pathology_vector_db_server.py
```

启动命令：

```bash
python3 pathology_vector_db_server.py \
  --host 127.0.0.1 \
  --port 8765 \
  --config /mnt/data_1/yds/RAG/Hybrid_milvus/总版/insert/config.yaml
```

参数说明：

```text
--host    服务监听地址，默认 127.0.0.1
--port    服务端口，默认 8765
--config  配置文件路径，默认 insert/config.yaml
--topk    服务默认返回条数；不传时使用 config.yaml 中 retrieval.topk
```

HTTP 接口：

```text
GET  /health
POST /search
```

POST `/search` 示例：

```bash
curl -s http://127.0.0.1:8765/search \
  -H 'Content-Type: application/json' \
  -d '{"query":"p16和Ki-67在宫颈病变病理诊断中的意义","topk":3}'
```

停止服务：

```text
在服务所在终端按 Ctrl+C
```

## 代码二：call_pathology_vector_db.py

作用：提供命令行调用和 Python 函数调用。

完整路径：

```bash
/mnt/data_1/yds/RAG/Hybrid_milvus/总版/call_pathology_vector_db.py
```

命令行调用：

```bash
python3 call_pathology_vector_db.py '宫颈癌的病理诊断要点是什么？' --topk 3 --json
```

参数说明：

```text
query            位置参数，检索问题；不传时使用默认测试问题
--topk           返回结果条数，默认 5
--json           输出完整 JSON；不加时输出简洁文本
--server-url     常驻服务地址，默认 http://127.0.0.1:8765
--no-server      不走常驻服务，直接本地加载 Milvus 和模型
--strict-server  服务不可用时直接报错，不回退本地加载
--timeout        请求常驻服务的超时时间，默认 120 秒
--config         本地直连模式使用的配置文件，默认 insert/config.yaml
--light-output   调试用，只取 ID 等轻量字段；正式检索不要开
```

默认逻辑：

```text
1. 优先请求 http://127.0.0.1:8765/search
2. 如果服务不可用，默认回退为本地直连加载
3. 如果加 --strict-server，服务不可用时不会回退
```

强制走常驻服务，服务不可用就报错：

```bash
python3 call_pathology_vector_db.py '宫颈癌病理类型' --topk 5 --json --strict-server
```

指定服务地址：

```bash
python3 call_pathology_vector_db.py '宫颈癌病理类型' \
  --topk 5 \
  --json \
  --server-url http://127.0.0.1:8765
```

不走服务，直接本地加载：

```bash
python3 call_pathology_vector_db.py '宫颈癌病理类型' --topk 5 --json --no-server
```

注意：`--no-server` 会重新加载模型和 Milvus Lite 库，首次启动会很慢，不推荐高频调用。

## Python 调用示例

推荐在业务代码中调用常驻服务：

```python
from call_pathology_vector_db import search_via_server

result = search_via_server(
    "宫颈癌的病理诊断要点是什么？",
    topk=3,
    server_url="http://127.0.0.1:8765",
)

for item in result["results"]:
    print(item["score"], item["file_name"], item["text"])
```

如果必须在 Python 内直接加载本地库：

```python
from call_pathology_vector_db import search

result = search("宫颈癌的病理诊断要点是什么？", topk=3)
```

注意：直接调用 `search()` 每次创建检索器都会加载模型和 Milvus，适合测试，不适合服务化高频调用。

## 配置文件说明

默认配置文件：

```bash
/mnt/data_1/yds/RAG/Hybrid_milvus/总版/insert/config.yaml
```

关键配置：

```yaml
milvus:
  uri: /mnt/data_1/yds/RAG/Hybrid_milvus/总版/数据库/bm25.db
  collection: cervix_v3
  dims_dense: 1024

paths:
  model_path: /mnt/data_1/yds/RAG/Hybrid_milvus/总版/pretrained_models/BAAI/bge-m3
  stats_out_dir: /mnt/data_1/yds/RAG/Hybrid_milvus/总版/all_data/stats_v2
  vocab_path: /mnt/data_1/yds/RAG/Hybrid_milvus/总版/all_data/word_txt/vocab_BM25.txt

retrieval:
  topk: 20
  fusion:
    weights:
      dense: 0.6
      sparse: 0.4
```

常用可调项：

```text
retrieval.topk                 默认返回条数
retrieval.fusion.weights       dense/sparse 融合权重
retrieval.fusion.lang_adapt    中英文自适应稀疏权重
milvus.uri                     Milvus Lite 文件路径或 Milvus 服务地址
milvus.collection              Collection 名称
paths.model_path               BGE-M3 模型路径
```

一般只建议调整 `topk` 和融合权重。不要随意改 `milvus.uri`、`collection`、`dims_dense`、`model_path`，否则可能连到错误库或向量维度不匹配。
